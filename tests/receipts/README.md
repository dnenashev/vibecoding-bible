# Receipts

Каталоги вида `<timestamp>/` создаёт `tests/run_forward_cases.py`. Каждый содержит:

- `run.json` — метаданные прогона и все записи;
- `<case_id>.json` — ответ агента и разбор judge по одному кейсу;
- `report.md` — отчёт по шаблону из `SCORING.md`.

Сырые прогоны не коммитятся: они содержат полные ответы моделей и объёмны.
В репозиторий попадает только release receipt (`tests/release-receipt.template.md`),
подтверждённый человеком, и, при необходимости, отдельный сохранённый прогон,
на который ссылается release verdict.
