# Пример: expectation gate в ProjectAdapter

Иллюстрация к разделу «StageContract» в [`references/agent-harness.md`](../../references/agent-harness.md). Это пример одного проекта, а не требование канона: другой проект реализует гейт средствами своей среды.

Канон требует, чтобы ожидание было зафиксировано до действия. Он не требует конкретной реализации. Ниже — один рабочий способ.

## Где живёт гейт

Гейт принадлежит ProjectAdapter, а не Harness Core: он зависит от инструментов конкретной среды. Core лишь читает `expectation_policy` текущей стадии и передаёт её adapter.

## Реализация через hook агентного хоста

Для Claude Code — `PreToolUse` hook на инструменты с побочным эффектом:

- hook читает `expectation_policy` активной стадии;
- при `none` пропускает вызов без изменений;
- при `per_consequential_action` пропускает read-only инструменты и требует ожидание для мутаций, деплоя, платных вызовов и внешних записей;
- при `per_action` требует ожидание для каждого вызова;
- отсутствие свежей записи ожидания даёт отказ с кодом, который агентный хост показывает как обратную связь.

Существенно: **отказ бесплатен**. Он не расходует attempt budget, не пишется в журнал как failure и не наказывает агента. Он просто не пускает действие вперёд.

## Фиксация ожидания

```
vibe predict --claim "миграция добавит 2 колонки в orders, строки не тронет" \
             --because "проверяю, что down-миграция обратима"
```

Команда пишет утверждение, вычисляет `committed_hash` и сохраняет метку времени. После действия adapter сверяет наблюдаемый результат с утверждением и записывает `verdict` в receipt.

Хеш нужен ровно для одного: он делает невозможным дописать ожидание задним числом. Без него запись становится самоотчётом агента, который канон не считает evidence.

## Что считать дорогим действием

Проект перечисляет свой список. Для типичного репозитория: деплой, миграция, запрос к production, полный прогон CI, платный вызов модели, внешняя мутация. Всё, что выводится из уже собранных артефактов — логи, coverage, AST, история git, снятые трейсы — дорогим не является и гейта не требует.
