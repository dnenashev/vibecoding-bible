# Проверка колонки Claude Code: 2026-08-22

Колонка Claude Code в [`host-adapters.md`](../skills/vibecoding-bible/references/host-adapters.md)
была написана по документации и ни разу не сверена с работающей средой. Сверка проведена
внутри сессии Claude Code, evidence — фактическое состояние среды, не название хоста.

## Подтверждено

| Роль | Чем подтверждено |
|---|---|
| Вызов Библии | Skill присутствует в списке среды, доступен как `/vibecoding-bible` и через автоматический выбор по `description` |
| Делегирование bounded subtask | Инструмент запуска субагентов с отдельным контекстом; типы агентов объявляют собственные наборы инструментов |
| Планирование до изменений | Plan mode доступен: вход в режим и выход через утверждение плана |
| Независимая проверка изменений | Установлены команды review и security review, исполняемые отдельно от автора изменения |
| Изоляция незавершённой работы | Изоляция сессии и делегированной задачи в отдельном worktree доступна как примитив |
| Долгая возобновляемая работа | Возобновление прогона по идентификатору, фоновые задачи и расписания — примитивы хоста, а не внешний harness |

## Расхождения, устранённые в 2.2.0

**Hooks и списки разрешённых инструментов заявлялись как имеющиеся.** Файл `settings.json`
отсутствует и в пользовательской, и в проектной области. Механизм в хосте есть,
конфигурации нет — значит автоматическая проверка на событие фактически не выполняется.
В таблице оговорено; в правила добавлено «наличие механизма не равно его настроенности».

**Строка «долгая возобновляемая работа» отправляла во внешний harness.** Для этого хоста
неверно: примитив встроен. Строка исправлена, добавлено правило проверять, не появился ли
примитив в хосте, прежде чем предлагать внешний обход.

**Роли изоляции от `main` в таблице не было вообще** — при том что процесс исправления
багов требует отдельного worktree. Строка добавлена, согласована с
[`bug-repair.md`](../skills/vibecoding-bible/references/bug-repair.md).

## Ограничение

Корпус forward-cases прогонялся в режиме перечисления, без `--execute`. Изменение
затрагивает references и документацию, публичные enum и маршрутизацию не меняет, поэтому
полный прогон агентом не запускался. Это ограничение, а не подтверждение.
